# omarchy-desk

Personal Omarchy desktop tweaks. One folder per piece.

The cyberpunk theme lives on its own: [ha-anzu/omarchy-cyberpunk](https://github.com/ha-anzu/omarchy-cyberpunk).

## Pieces

- [touch-scroll](touch-scroll/) — one-finger touchscreen swipe scrolls the columns when the workspace layout is scrolling.
- [elan-press](elan-press/) — press driver for the ELAN power-button readers `04f3:0c6e`, `04f3:0c4f`, and `04f3:0c63`, with a rebuild if a later package drops it.
